## Contents

The reference covers public bindings from `@hia-doc/cem-adapter`, `@hia-doc/htmdoc-producer`, `@hia-doc/htmdoc-runner`, `@hia-doc/htmdoc-spec`, `@hia-doc/html-doc-adapter`, `@hia-doc/html-doc-extractor`, `@hia-doc/html-doc-source-map` and `@hia-doc/html-parser`. It includes original API documentation, current/legacy configuration and extraction schemas, static declaration data, source maps and authorized complete sources.

## Publication

`snapshot.json` pins the source commit, publication identity, production registry and complete archive digests. GitHub Actions verifies every archived file, native fields, scoped public bindings, maps and full-source downloads before deployment. Generated content is supplied through a fixed release archive.

To update the site, build the source repository, validate both locales, publish the fixed archive and report, and update the snapshot. Version and language targets select this HTML partition.

## Command reference

The generated reference includes `htmdoc` and `htmdoc-handoff`, retaining their independent parsing and output rules. It provides localized usage, package and version identities, defaults, examples, exit results, static pages and authorized declaration-source links. Native descriptions, parser observations and original HIA documents remain available under `commands/` beside the independent website projection. Source positions are declaration-line anchors.
